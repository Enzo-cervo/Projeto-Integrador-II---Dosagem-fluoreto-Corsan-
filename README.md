# Projeto Integrador II – Dosagem de Fluoreto CORSAN

Este repositório contém os arquivos relacionados ao desenvolvimento de um sistema de automação para bomba dosadora de fluoreto aplicado a uma estação de tratamento de água.

O projeto busca automatizar o controle da dosagem de fluoreto, reduzindo a dependência de ajustes manuais e contribuindo para maior precisão, segurança e confiabilidade no processo de fluoretação.

## Objetivo do projeto

Desenvolver um sistema de automação baseado em microcontrolador para controle da bomba dosadora de fluoreto, com possibilidade de registro, organização e monitoramento digital dos dados operacionais.

## Estrutura do repositório

- `src/`: códigos desenvolvidos para o ESP32;
- `docs/`: documentação técnica e descrição do projeto;
- `hardware/`: diagramas elétricos, conexões e lista de componentes;
- `iot/`: informações relacionadas ao monitoramento digital e integração com Grafana;
- `testes/`: registros de testes de funcionamento em bancada;
- `imagens/`: imagens e diagramas utilizados na documentação.

## Tecnologias utilizadas

- ESP32;
- Arduino IDE;
- Linguagem C/C++;
- Sensor de vazão;
- Conversor de sinal PWM para saída analógica;
- Fonte 24 Vcc;
- Fonte 5 Vcc;
- Monitoramento digital;
- Grafana.
