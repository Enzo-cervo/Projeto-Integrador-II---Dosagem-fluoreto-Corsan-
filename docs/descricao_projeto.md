# Descrição do projeto

O projeto consiste no desenvolvimento de um sistema de automação para bomba dosadora de fluoreto aplicada a uma estação de tratamento de água.

A proposta utiliza um microcontrolador ESP32 para auxiliar no controle da dosagem de fluoreto, considerando informações operacionais do processo, como a vazão da água. O sistema busca reduzir a dependência de ajustes manuais e contribuir para maior precisão, segurança e confiabilidade na operação.

Além do controle da bomba dosadora, o projeto prevê recursos de registro, organização e monitoramento digital dos dados, possibilitando melhor acompanhamento do funcionamento do sistema.
