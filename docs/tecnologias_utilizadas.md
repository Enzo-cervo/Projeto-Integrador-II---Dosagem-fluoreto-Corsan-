# Tecnologias utilizadas

As principais tecnologias e recursos previstos para o desenvolvimento do projeto são:

- ESP32;
- Arduino IDE;
- Linguagem C/C++;
- Sensor de vazão;
- Conversor de sinal PWM para saída analógica;
- Fonte de alimentação 24 Vcc;
- Fonte de alimentação 5 Vcc;
- Monitoramento digital de dados;
- Grafana para visualização de informações operacionais.
